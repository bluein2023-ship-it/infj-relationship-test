# INFJ 关系适配度测试

30道ABCD情境选择题，六个维度、10分制。适合在手机浏览器完成。

## 使用

直接打开 `index.html`，无需安装或构建。若启用 GitHub Pages，可通过公开链接访问。

## GitHub Pages 发布

进入仓库 **Settings → Pages**，将 **Build and deployment → Source** 设置为 **Deploy from a branch**，选 **main** 和 **/(root)**，点击 **Save**。

预期公开地址：`https://bluein2023-ship-it.github.io/infj-relationship-test/`（仅在 Pages 成功启用且部署后可用）。

## 测评说明

- 关系信号与沟通、情绪回应与理解、个人边界与独立、冲突与修复能力、未来规划与价值观、日常经营与行动
- 每维度5题，30题每题按0–3分评分，六维度等权换算至10分
- 结果提供薄弱维度与逐题问题定位
- 本测评为关系自我观察工具，不是科学验证的MBTI匹配概率或临床测评；严重的边界与安全问题不能被高总分抵消

不存储、不上传答题结果。
